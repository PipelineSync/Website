# PipelineSync website: working notes for Claude

Static Eleventy 3 site for pipelinesync.net (HubSpot Gold Solutions Partner). Netlify deploys `main`; every PR gets a deploy preview. See README.md for structure.

## SEO and AI search roadmap (always follow)

The owner adopted a 12-month SEO and AI search plan in October 2026. **Every website change should follow it.**

- Plan and status: `docs/seo/roadmap.md`. Update its status table when an item ships.
- Full plan: `docs/seo/PipelineSync-SEO-AI-Search-Plan.pdf`. Supporting docs in `docs/seo/` (keyword map, content plan with article briefs, measurement plan, structured data, off-site playbook).
- One primary keyword per URL (`docs/seo/keyword-map.md`); do not create pages that compete with an existing page's keyword.
- New content: answer-first structure (question as H2, direct 40–60 word answer, then detail, FAQ), internal links to the matching service page and `/resources/`, follow `docs/seo/content-plan.md` §7.
- Never invent facts, statistics, client names, prices, reviews, or results. Use `TODO(owner)` and ask.
- Never change an existing URL without a 301 in `src/_redirects`.

## Where things live

- Business facts, profile links, analytics IDs: `src/_data/site.json`. Services: `src/_data/services.json`. FAQs: `src/_data/faq.json`.
- JSON-LD is generated by `buildGraph()` in `.eleventy.js` from page front matter (`pageType`, `breadcrumbName`, `serviceId`, `faqs`). Do not hand-write `schema:` blocks.
- Service pages use `src/_includes/layouts/service.njk` with content in front matter.
- Design system: `assets/css/site.css`; shared JS: `assets/js/site.js`; analytics events: `assets/js/analytics.js`.
- AI search: `src/robots.txt` (AI crawler policy), `src/llms.txt.njk`, IndexNow plugin in `netlify/plugins/indexnow`.

## Before every push

- `npm run check` must pass with 0 failures (it builds the site and enforces SEO, link, image and JSON-LD rules).
- After changing a page title, run `npm run build && npm run og-images` and commit the updated `assets/img/og/*.png`.
- New icons: rerun `tools/build-icon-subset.py` (see its header). New images: `tools/optimize-images.py`.
- Keep features working: loading screen, custom cursor, ROI calculator, HubSpot consultation modal (portal 247123252, form 925b2a78-2998-4846-a6e8-a7514007fb93), interactive Revenue Pipeline hero, resource tabs and card links, integrations filter, reduced-motion support.
